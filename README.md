# Сайт «Эвакуатор Казань» с заявками в Telegram

## Что уже готово
- Адаптивный сайт с фотографией эвакуатора.
- Форма заявки: имя, телефон, автомобиль, маршрут.
- Сервер отправляет заявки в Telegram через бота.
- Токен бота хранится только на сервере, не в HTML.
- Базовая проверка полей и ограничение частоты заявок.

## Что нужно сделать один раз

### 1. Создать Telegram-бота
1. Откройте Telegram и найдите официального бота `@BotFather`.
2. Отправьте `/newbot` и следуйте подсказкам.
3. Сохраните выданный токен. Не публикуйте его и никому не пересылайте.

### 2. Узнать свой Chat ID
1. Откройте созданного бота по ссылке, которую выдаст BotFather.
2. Нажмите Start и отправьте ему любое сообщение.
3. Получите свой личный chat ID через надёжный способ/инструмент получения ID Telegram.
   Не отправляйте токен бота в публичные чаты или сайты.

### 3. Разместить сайт на Node.js-хостинге
Загрузите эту папку на хостинг, который поддерживает Node.js 18 или новее.
В настройках переменных окружения хостинга добавьте:
- `TELEGRAM_BOT_TOKEN` — токен от BotFather
- `TELEGRAM_CHAT_ID` — ваш личный chat ID

Команда запуска: `npm start`

После запуска откройте домен сайта, отправьте тестовую заявку — сообщение должно прийти в чат с ботом.

## Важно
- Не вставляйте токен бота в `index.html` или другие публичные файлы.
- Не отправляйте токен бота мне в чат. Введите его только в защищённые переменные окружения хостинга.
- Пока вы не добавили переменные и не опубликовали проект на хостинге, сайт не сможет доставлять реальные заявки.
- Добавьте на сайт свои реальные контакты и проверьте местные требования к политике конфиденциальности и обработке персональных данных.
